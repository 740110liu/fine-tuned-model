# 讯飞星辰MaaS平台 - 数据准备操作指南

## 平台地址

https://training.xfyun.cn/modelSquare

## 第一步：注册登录

1. 访问上述网址
2. 使用讯飞账号登录（或注册新账号）
3. 进入"模型广场"页面

## 第二步：使用数据处理工具

### 工具1：问答对抽取（推荐先使用）

**用途：** 从原始文本中自动切分问答对，准确率90%+，覆盖率75%+

**操作步骤：**
1. 在左侧菜单找到"数据管理" → "数据工具"
2. 选择"问答对抽取"
3. 上传原始文本文件（TXT/DOC/PDF）
4. 点击"开始抽取"
5. 等待处理完成（通常几分钟）
6. 下载抽取结果（JSONL格式）

**适用场景：**
- 从专业文档中提取问答对
- 从教材、手册中生成训练数据
- 扩充现有数据集

### 工具2：数据增强

**用途：** 批量增强数据集，支持选择增强倍数和质量

**操作步骤：**
1. 在"数据工具"中选择"数据增强"
2. 上传您的 `automation_advisor.jsonl` 文件
3. 选择增强倍数：
   - 2倍：轻度扩充
   - 3倍：中度扩充
   - 5倍：大幅扩充
4. 选择增强质量（推荐"高质量"）
5. 点击"开始增强"
6. 下载增强后的数据

**建议：**
- 当前151条 → 增强到300-500条效果更好
- 保留原始数据，增强数据作为补充

### 工具3：Prompt工程

**用途：** 50+常见prompt模板，优化instruction格式

**操作步骤：**
1. 在"数据工具"中选择"Prompt工程"
2. 浏览预设模板：
   - 问答类
   - 分类类
   - 生成类
   - 分析类
3. 选择适合的模板
4. 应用到您的数据集
5. 导出优化后的数据

**推荐模板：**
- "专业导师问答"模板
- "知识问答"模板
- "对话生成"模板

## 第三步：数据格式转换

讯飞平台导出的数据可能需要格式转换，确保符合 Alpaca 格式：

```json
{
  "instruction": "任务指令",
  "input": "输入内容",
  "output": "期望输出",
  "system": "系统提示词（可选）",
  "history": [["历史问题", "历史回答"]]
}
```

### 使用我们的验证脚本检查格式：

```bash
python scripts/validate_data.py data/your_exported_data.jsonl
```

### 使用预处理脚本转换格式：

```bash
python scripts/preprocess.py --input data/raw/ --output data/processed/
```

## 第四步：数据集划分

将处理好的数据划分为训练集、验证集、测试集：

```bash
# 推荐比例：70% 训练 / 15% 验证 / 15% 测试
python scripts/split_data.py --input data/processed.jsonl --output data/
```

## 推荐工作流

```
1. 原始文档（教材、手册、FAQ）
   ↓
2. 讯飞平台 - 问答对抽取
   ↓
3. 讯飞平台 - 数据增强（2-3倍）
   ↓
4. 讯飞平台 - Prompt优化
   ↓
5. 导出 JSONL 格式
   ↓
6. 本地验证格式
   ↓
7. 数据集划分
   ↓
8. 用于微调
```

## 注意事项

1. **免费额度**：讯飞平台通常提供免费额度，但可能有限制
2. **数据质量**：增强后的数据需要人工抽检质量
3. **格式兼容**：确保导出格式与微调脚本兼容
4. **备份数据**：处理前备份原始数据

## 常见问题

**Q: 讯飞平台需要付费吗？**
A: 数据处理工具通常有免费额度，具体以平台说明为准

**Q: 增强后的数据质量如何保证？**
A: 建议人工抽检10-20%的数据，确保质量

**Q: 可以同时使用多个工具吗？**
A: 可以，建议按顺序使用：抽取 → 增强 → 优化

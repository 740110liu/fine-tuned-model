# 数据集说明

## 讯飞星辰MaaS平台数据格式

平台支持 **JSON / JSONL / CSV** 格式，使用 **Alpaca** 标准格式。

### 核心字段

| 字段 | 必填 | 说明 |
|------|------|------|
| instruction | 是 | 任务指令，与 input 拼接形成模型输入 |
| input | 否 | 输入内容（可为空字符串） |
| output | 是 | 期望的模型输出 |
| system | 否 | 系统提示词，提供额外上下文 |
| history | 否 | 对话历史，格式为 `[["问", "答"], ...]` |

### 数据示例

#### 情感分类
```json
{"instruction": "你是一个情感分析助手，目标是辨别推文的情感倾向，情感倾向分为积极和消极。接下来，我会给你推文的内容，请你告诉我情感分析的答案", "input": "一百多和三十的也看不出什么区别，包装精美，质量应该不错", "output": "积极"}
```

#### 商品分类
```json
{"instruction": "你是一个专业的商品分类助手，需要依据给定的商品分类标准，对输入的商品名称进行精准分类。直接输出类型标签，不需要解释：", "input": "樱之歌蓝色之恋5件套日式釉下彩纯手绘家用餐具套装", "output": "家居"}
```

#### 诗词生成
```json
{"instruction": "请根据以下主题创作一首七言绝句", "input": "春日", "output": "春风拂面柳丝长，燕子归来绕画梁。桃花流水窅然去，别有天地非人间。"}
```

### 数据集划分建议

| 数据集 | 比例 | 用途 |
|--------|------|------|
| 训练集 | 70% | 模型训练 |
| 验证集 | 15% | 超参调优、模型选择 |
| 测试集 | 15% | 最终评估 |

### 常见问题

- 数据集校验失败：检查字段名是否为 `instruction/input/output`（而非 prompt/text/label）
- 格式转换：使用 `scripts/preprocess.py` 将自定义格式转为 Alpaca 格式
